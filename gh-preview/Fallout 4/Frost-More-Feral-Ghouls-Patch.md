## Description

A patch to make the **[More Feral Ghouls](https://www.nexusmods.com/fallout4/mods/43441)** mod compatible with FROST. 
This includes leveled character changes, balance changes, immersion changes and more.
It is compatible with my Frost FGEP Patch.

---
## Technical Information

This patch was made for **version 2.0** of the **[More Feral Ghouls](https://www.nexusmods.com/fallout4/mods/43441)** mod.
You should also use the [Frost Cell Fixes (FCF) patch](https://www.nexusmods.com/fallout4/mods/59652) for More Feral Ghouls to fix a small issue with precombines.
