## Description

This mod contains two plugins. One changes the **62 garden gnomes** in Far Harbor. 
They now explode in a **nuclear fashion** if they get damaged.
I recommend to install & forget this mod, so that you eventually wonder where that random explosion came from
when wandering through Mt. Desert Island.

The other plugin adds a **Tactical Thermonuclear Gnome grenade** that you can craft at the Chemistry Workbench.

The plugins are esl-flagged esp files, so they don't count towards the plugin limit.

They are also independent from each other, you can enable both or only one of them.
