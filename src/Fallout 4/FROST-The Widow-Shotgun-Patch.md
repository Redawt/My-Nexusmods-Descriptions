## Description

This mod patches The Widow Shotgun mod for FROST.

To further balance things, it is not possible to craft the legendary ammos for the shotguns any more. They are not balanced for
FROST. If this bothers you, feel free to use xEdit to revert these changes.

Furthermore, you need to pick a master lock to get the shotgun (you need to be level 18 to get the master lock pick perk).
Why did I put it behind the a master lock? Because it is too easy to get to Concord if you choose certain starting locations in FROST. If you get this shotguns at level 1 it would be a bit lame. 


---
## Technical Details

This patch was made for **version 1.1 ** of the **[The Widow Shotgun](https://www.nexusmods.com/fallout4/mods/19619)**.
You need to install this patch right after you've installed The Widow Shotgun.
