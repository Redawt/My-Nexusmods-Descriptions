## Description

This mod patches [Crossbows of the Commonwealth](https://www.nexusmods.com/fallout4/mods/10484?tab=files) for FROST.


---
## Technical Details

This patch was made for **version 1.4** of the [Crossbows of the Commonwealth](https://www.nexusmods.com/fallout4/mods/10484?tab=files) mod.
You need to install this patch right after you've installed Crossbows of the Commonwealth.
