[size=4][b]Description[/b][/size]
A script that can dynamically inject an infinite amount of Leveled Lists into other Leveled Lists.

Why use this script instead of the other LL injection scrips on the Nexus?
My script uses structs and arrays, and can support an unlimited amount of leveled list injections. Other scripts that try to do the same often only offer a limited amount of Leveled Lists injections.

[size=4][b]Required Knowledge:[/b][/size]
You need to know how Leveled Lists and Script Properties in the Creation Kit work, and very basic knowledge about how to make a quest.

[size=4][b]Tutorial:[/b][/size]
A tutorial can be found in the [url=https://www.nexusmods.com/fallout4/articles/3438]articles section[/url].

[size=4][b]Limitations[/b][/size]
Infinite means in this case means 256. A leveled list can only contain 255 entries. This is irrelevant though, as most leveled lists in the vanilla files and in modded files don't contain more then 50 entries. The 256 limitation comes from the fact that Bethesda used a "Short" datatype for indexing entries in leveled lists.
