[size=5][b]Description[/b][/size]
This is patch for the [b][url=https://www.nexusmods.com/fallout4/mods/57181]Feral Ghouls Expansion Pack[/url][/b] to make it compatible with FROST.

[line]
[size=5][b]Technical Information[/b][/size]

This was made with [b]version 1.5[/b] of the [b][url=https://www.nexusmods.com/fallout4/mods/57181]Feral Ghouls Expansion Pack[/url][/b].

This patch was created for the [color=#d98f40][b]SCRIPT INJECTION[/b][/color] version of FGEP. 
It is not compatible with other the other version.

It is compatible with the optional file that adds Feral Tanks, but I don't recommend to use that optional file

You can install this mid-playthrough, but you need to install it together with FGEP.

This mod is compatible with [color=#d98f40][b]More Feral Ghouls[/b][/color] and its Frost patch.

[line]
[size=5][b]Details[/b][/size]

[list][*]Renamed all new ghouls to "Feral Ghouls" (as is standard with Frost)
[*]Changed damage, health and resistances of the new ghouls
[*]Reduced the Feral Exploder explosion size
[*]Adjusted body part damage that attacks to certain limbs do more or less damage to the ghouls (Body Part Data)
[*]Most of the new ghouls have now the abilities/stat buffs from normal ghouls
[*]Replaced the Institute clothes certain ghouls can wear with Federation Outfits
[*]The Feral Ghoul with Power Armor plates is now very resistant against head-shots, but has some other weaknesses
[*]The loot of Feral Ghouls was patched accordingly
[*]Feral Bile now gives 1 Bone and 1 Acid scrap instead of 5 Nuclear Material scrap
[*]Feral Tanks only spawn if you use the optional patch from the original mod that places Feral Tanks into the world
[*]Legendary Spawns from FGEP were removed
[*]And some other minor details
[/list]
